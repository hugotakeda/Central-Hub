Central Hub is a lightweight Windows desktop app for discovering and managing peripherals, with a minimal black-and-graphite interface and real device data.

### Downloads

- **Central-Hub-0.9.1-Setup.exe** — recommended Windows x64 installer.
- **CentralHub.exe** — standalone Windows x64 executable; requires Microsoft Edge WebView2 Runtime.
- **Central-Hub-0.9.1-fonte.zip** — source snapshot of this release.
- **SHA256SUMS.txt** — SHA-256 checksums for these downloads.

Close older Central Hub instances before launching this version. The current app interface is in Brazilian Portuguese.

### Features and fixes

- Physical mouse, keyboard and headset cards, with generic receivers, motherboard audio and internal controllers kept in Interfaces.
- Protocol-confirmed Aula F75 identification over its 2.4 GHz receiver, with product photo and connection details.
- Last confirmed wireless F75 identity retained during the session when a later query is silent, clearly distinguished from a current reply.
- Logitech G Pro X Superlight original: reported DPI/polling options, software/onboard mode and battery readings.
- Aula F75 over USB: built-in lighting effects, brightness and speed controls.
- Windows audio controls for supported endpoints, including HyperX Cloud Flight.
- Read-only hardware diagnostics, exportable reports, and a focused manual keyboard/mouse input test.
- Online product photo suggestions with source attribution, local caching, manual search preview and local photo overrides.

### Compatibility limits

- Detection does not imply universal configuration support. Generic receiver IDs alone do not prove that a wireless peripheral is connected.
- **Aula F75 lighting configuration requires USB in this release.** Wireless identification does not enable the wired configuration protocol on the receiver. If the keyboard is asleep, press a key and refresh.
- G Pro TKL wired detection and photo are included; its RGB/remapping controls are not integrated.
- Headset battery/DSP controls, firmware updates, macros and onboard profile writing are not integrated.
- An online photo may be unavailable or show a different visual variant; suggestions can be corrected or hidden.

### Validation

The 0.9.1 build passed **42 frontend tests and 30 native unit tests**. Two physical hardware-write tests remain ignored by default. Wireless F75 identification was confirmed against a real receiver returning model CD. Native Windows release compilation and NSIS installer packaging completed successfully. Configuration-write tests were not rerun for this release's filtering/identification changes; see the repository's validation notes for the earlier physical checks and the limits of testing.
