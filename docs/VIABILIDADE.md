DPI e polling operam no estado ativo e exigem controle por software. Não há gravação de perfis onboard. Outro programa pode reaplicar seus próprios valores.

O receptor Compx 3554:FA09 continua no diagnóstico. O F75 configurável desta entrega é a interface USB 258A:010C cujo modelo retornado é CD.

A iluminação usa o controlador interno do teclado; não precisa transmitir cores continuamente. Os efeitos são numerados conforme o firmware. Não há prévia de cor fictícia.
